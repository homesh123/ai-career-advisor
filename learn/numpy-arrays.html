🔢 NumPy and vectorisation: fast maths on arrays

EnglishHinglish

🏠 Real-life example

Imagine stamping the date on 1,000 envelopes one by one by hand, versus pressing a single printing plate that stamps a whole sheet at once. A Python 'for' loop works one item at a time; NumPy vectorisation operates on the whole array at once in fast C code.

💡 In simple words

Every machine learning library (Pandas, scikit-learn, PyTorch) is built on multi-dimensional arrays of numbers. A 1D NumPy array is a vector (like a single column of prices), and a 2D array is a matrix (rows of customers × columns of features). Every array has a .shape, such as (1000, 5). With vectorisation and broadcasting, you write 'prices * 1.18' with no loops, and NumPy applies it to a million numbers in milliseconds.

🪜 Step by step

  1. Create arrays from lists or helpers: np.array([1, 2, 3]), np.zeros((100, 10)), np.arange(0, 10, 2).
  2. Inspect shape and data type first: arr.shape (rows, columns) and arr.dtype (float32, int64).
  3. Slice and filter without loops: X[:, 0] (first column), X[X > 0] (boolean mask for positive values).
  4. Use axis wisely in aggregations: X.mean(axis=0) averages down each column; X.mean(axis=1) averages across each row.
  5. Use dot products and matrix multiplication (X @ w or np.dot) for linear models and cosine similarity.

🔑 Key terms

ndarray
A fast, fixed-type grid of numbers in NumPy (1D vector, 2D matrix, or higher).
Vectorisation
Doing maths on whole arrays at once instead of looping in Python.
Broadcasting
NumPy's rule for combining arrays of compatible shapes, like adding one row to every row of a matrix.

👀 See it in action

python
import numpy as np

prices = np.array([100.0, 250.0, 400.0])     # shape (3,)
with_gst = prices * 1.18                      # vectorised: [118., 295., 472.]

# Standardise each column of a (1000, 4) feature matrix X
X_norm = (X - X.mean(axis=0)) / X.std(axis=0)

No loops needed: broadcasting subtracts each column's mean from all 1,000 rows.

⚠️ Common mistakes to avoid

  • Confusing shape (N,) (a 1D vector) with (N, 1) (a 2D column) when broadcasting, causing an unexpected (N, N) matrix! Check .shape after operations.
  • Modifying a slice without realising it's a view of the original array. Use .copy() when you want an independent copy.

✅ Quick check

Why do ML engineers prefer 'np.dot(w, x)' or 'X * 2' over a Python 'for' loop?

  1. Python loops cannot do multiplication
  2. Vectorised NumPy operations run in compiled C/SIMD code and are 50–100× faster
  3. It uses more memory on purpose
Show answer

B. Vectorised NumPy operations run in compiled C/SIMD code and are 50–100× faster: Python loops check types on every single element; NumPy processes contiguous memory blocks in C at hardware speed.

🙋 Questions learners ask

How are NumPy arrays and PyTorch tensors related?

They have almost the same API (.shape, slicing, broadcasting, @). PyTorch tensors add two things: they can run on GPUs and track gradients for deep learning.

Why does float32 matter more than float64 in AI?

float32 uses half the memory of float64 and runs much faster on GPUs, while keeping more than enough precision for machine learning.

🎯 Asked in interviews on this topic

Try answering out loud first, then open the model answer.

Why is NumPy vectorisation so much faster than Python loops, and what is broadcasting?

💬

In a Python loop, the interpreter checks types and dispatches operations element by element, which has huge overhead. A NumPy array stores numbers of one fixed type in a contiguous block of memory, so vectorised operations like a * b or X @ W run in compiled C and SIMD instructions across the whole array at once, often 50 to 100 times faster. Broadcasting lets NumPy do arithmetic on arrays of different shapes without copying data by stretching dimensions of size 1, such as subtracting a 1D column mean (1, d) from every row of a 2D matrix (n, d).

✅

  • Contiguous typed memory + C/SIMD loops vs Python interpreter overhead
  • Matrix multiplication (@), reductions with axis, and checking .shape
  • Broadcasting stretches dimensions of size 1 without copying memory
  • Watch out for unintentional (n, 1) + (1, n) creating an (n, n) matrix

📌 Remember

Check .shape first, and replace Python loops over numbers with vectorised array operations.
