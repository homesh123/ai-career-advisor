🎯 Two kinds of prediction: regression and classification

EnglishHinglish

🏠 Real-life example

A Swiggy app answers two different kinds of questions. 'How many minutes until delivery?' has a number as its answer: that's regression. 'Will this order be late: yes or no?' puts the order in a category: that's classification.

💡 In simple words

Regression predicts a continuous number, such as price, temperature or delivery time. Linear regression, the classic starting point, draws the best straight-line relationship between features and the number. Classification predicts a category, such as spam/not spam, fraud/genuine, or which of 10 product types. Logistic regression, despite its name, is a simple classification model that outputs a probability. Decision trees can do both. Always start with these simple models before trying anything complex.

🪜 Step by step

  1. Ask what the answer looks like. A number (price, delivery days) means regression. A category (spam or not, which product type) means classification.
  2. For regression, start with linear regression; measure error in real units (MAE: off by ₹1,200 on average).
  3. For classification, start with logistic regression; it gives a probability you can threshold.
  4. Compare with a dumb baseline: always predict the average, or always the most common class.
  5. Then try stronger models (random forest, gradient boosting) and keep the simplest one that clearly wins.

🔑 Key terms

Regression
Predicting a number, e.g. house price.
Classification
Predicting a category, e.g. spam or not.
Baseline
The simplest possible prediction, which your model must beat.

👀 See it in action

python
from sklearn.linear_model import LinearRegression, LogisticRegression

reg = LinearRegression().fit(X_train, delivery_minutes)   # regression
clf = LogisticRegression().fit(X_train, is_late)           # classification

reg.predict(X_new)          # → [32.5] minutes
clf.predict_proba(X_new)    # → [[0.8, 0.2]] → 20% chance of being late

Same features, two different questions, two different model types.

⚠️ Common mistakes to avoid

  • Treating categories as numbers, like city codes 1, 2, 3, so the model thinks city 3 is 'more' than city 1. Use one hot encoding.
  • Using accuracy for regression or MAE for classification. Each type has its own metrics.

🙋 Questions learners ask

Why is it called logistic 'regression' if it classifies?

Historical naming: it predicts a number, the probability, which is then turned into a class with a threshold.

Can one model do both?

Many algorithms have both versions, like decision trees and gradient boosting. You pick the version that matches your target.

🎯 Asked in interviews on this topic

Try answering out loud first, then open the model answer.

Explain supervised, unsupervised and reinforcement learning, with an example of each.

💬

Supervised learning learns from examples that have the right answer, called labels. For example, emails marked spam or not spam, so the model learns to predict spam. Unsupervised learning has no labels; it finds structure by itself, like grouping customers into segments by behaviour. Reinforcement learning learns by trial and error with rewards, like a game playing agent or a robot that gets a reward when it does the task well. LLMs also use reinforcement learning from human feedback to make answers more helpful.

✅

  • Supervised = labelled data, predicts a known target
  • Unsupervised = no labels, finds groups or patterns
  • Reinforcement = actions, rewards, learning by trial and error
  • A real example for each

How do you choose which model to use?

💬

I start with a simple baseline, like logistic regression or even a rule, so I know what "good" means. For tabular data, I'd then try gradient boosting because it's usually strongest. For images, text or audio, I'd use pretrained deep learning models or an LLM. Then I consider constraints: latency, cost, how much data I have, and whether the result must be explainable, for example in lending. I pick the simplest model that meets the target on validation data, because it's easier to maintain.

✅

  • Start with a baseline
  • Data type guides the family (tables → boosting; text/images → pretrained deep models)
  • Constraints: latency, interpretability, data size, cost
  • Simplest model that meets the goal

: Engineering judgement over chasing the fanciest model.

How would you implement logistic regression from scratch?

💬

I'd explain the steps, then code them in NumPy. One, initialise weights and bias to zeros. Two, compute z = X·w + b and the prediction p = sigmoid(z). Three, the loss is binary cross entropy. Four, the gradient is simple: dw = Xᵀ(p − y) / n and db = mean(p − y). Five, update w and b by subtracting learning rate times the gradient, and loop for some epochs. I'd add a check that the loss goes down, clip probabilities to avoid log of zero, and test on a tiny dataset where I know the answer.

✅

  • Sigmoid of a linear combination
  • Binary cross entropy loss
  • Gradient = Xᵀ(p − y)/n
  • Update loop; sanity checks for numerical stability

: ML coding rounds in 2026 often ask for algorithms from scratch, not just library calls.

How would you build a spam email classifier?

💬

Clarify: what counts as spam, and which mistake is worse? Usually marking a real email as spam is worse, so precision matters. Data: emails labelled spam or not. Features: start with text turned into numbers, using TF IDF, plus simple signals like number of links or the sender's history. Model: a baseline with logistic regression or naive Bayes, which works well for text, then compare with a fine tuned small language model if needed. Evaluate with precision and recall on a test set, and pick a threshold that keeps false positives very low. Deploy it as a service, collect "not spam" corrections from users, and retrain regularly because spammers change tactics.

✅

  • Clarify which mistake is worse
  • Text features (TF IDF) plus extra signals
  • Simple baseline first
  • Precision focused threshold; feedback and retraining

: A classic fresher design question: a full, simple pipeline with good reasoning.

📌 Remember

Number → regression. Category → classification. Start simple.
