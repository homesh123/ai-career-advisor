⚡ Production Python: async/await, Pydantic aur testing

EnglishHinglish

🏠 Asli zindagi ki misaal

Ek busy darshini cafe mein cashier agla order lene se pehle teen minute tawa ke saamne khaali khada nahi rehta. Jab paanch dose ek saath pak rahe hote hain, woh aur orders le leta hai. Yahi async/await hai. Aur kitchen mein kaam shuru hone se pehle token slip check karti hai ki item ka naam aur quantity sahi hai. Yahi Pydantic hai.

💡 Aasaan shabdon mein

AI services apna zyaadatar waqt LLM APIs aur databases ke network calls ka wait karne mein lagati hain. 'async def' aur 'await' ke saath Python har call ka line mein wait karne ke bajaye darjanon API requests ek saath chala sakta hai. Jab user ya LLM se data aata hai, to Pydantic models turant field ke naam aur types check karte hain taaki galat data saaf message ke saath wahin ruk jaaye. Iske saath package versions alag rakhne ke liye virtual environment (venv) aur logic test karne ke liye pytest use karo.

🪜 Step by step

  1. Har project ke liye alag environment banao: 'python -m venv .venv' aur packages install karne se pehle use activate karo.
  2. Request inputs aur LLM ke structured outputs ke liye Pydantic BaseModel banao taaki galat types ya missing fields turant pakde jaayein.
  3. Network calls ke liye async client (AsyncOpenAI, AsyncAnthropic, httpx.AsyncClient) ke saath 'async def' aur 'await' use karo.
  4. 'asyncio.gather' ke andar 'asyncio.Semaphore(10)' se concurrency limit karo taaki rate limit hit kiye bina ek saath 10 requests chalein.
  5. 'tests/test_app.py' mein pytest se unit tests likho aur har commit se pehle 'pytest' chalao.

🔑 Zaroori shabd

async / await
Slow network ya disk calls ka wait karte waqt Python ko doosre kaam karne deta hai.
Pydantic BaseModel
Ek class jo input data ko declared types ke hisaab se check aur convert karti hai.
pytest
Python ka standard testing tool: behaviour verify karne ke liye 'assert' wale chhote functions likho.

👀 Example dekho

python
import asyncio
from pydantic import BaseModel, Field

class Ticket(BaseModel):
    order_id: int
    urgency: str = Field(pattern="^(low|medium|high)$")

async def classify_all(items, call_llm):
    raw = await asyncio.gather(*(call_llm(x) for x in items))
    return [Ticket.model_validate(r) for r in raw]

Bahut saare items ke liye LLM ko parallel mein call karo, phir har response ko Pydantic se validate karo.

⚠️ Aam galtiyaan jinse bachna hai

  • 'async def' function ke andar 'time.sleep()' ya 'requests.get()' jaisa blocking code chalana, jo poore event loop ko rok deta hai. 'await asyncio.sleep()' aur 'httpx.AsyncClient' use karo.
  • LLM output pe 'json.loads()' se mile raw dictionaries pe bina Pydantic validation ke bharosa kar lena.

✅ Jaldi se check karo

Aapko 20 alag documents ke liye LLM API call karni hai. Kis cheez se yeh kaam ~10× tez poora hoga?

  1. Rate limits ke andar asyncio.gather se async calls ek saath chalana
  2. Variables ke naam ek akshar ke rakhna
  3. time.sleep() ke saath normal for loop
Jawaab dekho

A. Rate limits ke andar asyncio.gather se async calls ek saath chalana: LLM calls network pe wait karti hain: unhe ek saath chalane se waiting time judne ke bajaye overlap ho jaata hai.

🙋 Seekhne wale yeh poochhte hain

async/await kab madad karta hai aur kab nahi?

Yeh I/O-bound kaam mein madad karta hai: APIs, databases ya files ka wait. Bhaari CPU ya matrix maths ke liye NumPy/PyTorch ya multiprocessing use karo.

Python type hints aur Pydantic mein kya fark hai?

Normal type hints (x: int) sirf code chalne se pehle editor check karta hai. Pydantic app chalte waqt runtime pe asli data ko check aur convert karta hai.

🎯 Is topic pe interviews mein poochhe jaane wale sawaal

Pehle khud bolkar jawaab dene ki koshish karo, phir model answer kholo.

LLM se reliable JSON output kaise lete ho?

💬

Pehle provider ka structured output ya JSON mode schema ke saath use karo, jo model ko valid JSON tak seemit karta hai. Doosra, schema simple rakho, saaf field descriptions aur allowed values ke saath, aur temperature kam. Teesra, hamesha code se validate karo, jaise Pydantic se: types, required fields aur ranges check karo. Validation fail ho to error message ke saath ek baar retry karo, phir bhi fail ho to crash ke bajaye safe fallback, jaise item ko manual review ke liye mark karna. Aur failures log karo taaki prompt sudhre.

✅

  • Native structured output ya schema wala JSON mode
  • Simple schema, saaf descriptions, kam temperature
  • Code se validate (jaise Pydantic)
  • Error ke saath retry, phir safe fallback

: Production reliability; AI product engineer interviews mein bahut common.

Production Python AI services async/await aur Pydantic kyun use karti hain, aur live LLM calls ka kharcha kiye bina unhe kaise test karte ho?

💬

LLM aur vector DB calls apna 99% waqt network I/O ke intezaar mein bitaate hain. Synchronous Python mein 50 concurrent requests 50 threads block karti hain; async/await aur asyncio.gather (rate limits ke liye asyncio.Semaphore se bandha) ke saath ek worker darjanon waiting requests ek saath sambhaal leta hai. Pydantic boundary pe sakht types aur field constraints enforce karta hai—aane wali FastAPI requests pe bhi aur LLM se laute structured JSON pe bhi. CI mein tez aur muft test karne ke liye main LLM client inject karta hoon aur deterministic unit tests ke liye pytest mein mock karta hoon, jabki release se pehle asli model pe alag golden eval suite chalata hoon.

✅

  • async/await + asyncio.gather network I/O pe threads block hone se bachaata hai
  • Provider rate limits maan'ne ke liye asyncio.Semaphore se concurrency baandho
  • Pydantic runtime pe API inputs aur LLM structured outputs dono validate karta hai
  • Tez CI ke liye mocked LLM clients ke saath pytest + model quality ke liye golden eval suite

: AI Product, Agent aur Forward Deployed Engineers ke liye standard backend craft check.

Gande scanned PDFs ya real-time voice ke liye bharosemand multimodal pipeline kaise banate ho?

💬

Multi-column tables ya handwriting wale gande PDFs aur invoices mein saada OCR layout kho deta hai aur numbers galat padhta hai. Main pages ko 150–200 DPI pe render karta hoon, page ki photo aur nikaala hua text dono sakht Pydantic JSON schema ke saath Vision-Language Model ko deta hoon, aur baad mein deterministic code checks chalata hoon—jaise check karna ki line-item amounts ka jod sach mein invoice total ke barabar hai—aur gadbadi ko human review mein bhejta hoon. Voice AI ke liye STT → LLM → TTS ko ~800 ms ke andar rakhna hota hai, to main bolne ke pause pe partial transcripts stream karta hoon, LLM ke sentences tukdon mein TTS ko stream karta hoon, aur barge-in support karta hoon taaki user ke bolte hi audio turant ruk jaaye.

✅

  • Documents ke liye sakht JSON schema ke saath hybrid vision + OCR input
  • Deterministic validation (jaise line items ka jod = total) + human review queue
  • Voice AI: 800 ms ke andar streaming STT → LLM → TTS ya native speech-to-speech
  • Barge-in interruption sambhaalo aur images/audio mein PII chhupao

: Multimodal document aur voice pipelines 2026 mein hiring ka bada focus hain.
