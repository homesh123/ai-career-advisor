🫧 Unsupervised learning: clustering, PCA aur anomaly detection

EnglishHinglish

🏠 Asli zindagi ki misaal

Socho aapne bina naam likhe sikkon ka ek dabba mez pe palat diya. Chahe koi unke naam na bataye, aap unhe size, wazan aur rang dekhkar alag dheriyon mein baant doge — aur agar beech mein ek plastic ka button chhupa hai, to woh turant alag dikhega. Unsupervised learning yahi karta hai: bina labels ke milte-julte rows ke group banata hai (clustering), bahut saare columns ko chhota karta hai (PCA), aur ajeeb outliers pakadta hai (anomaly detection).

💡 Aasaan shabdon mein

Zyaadatar company data pe labels nahi hote. Unsupervised learning bina label wale data mein structure dhoondhta hai. K-means clustering har point ko uske sabse paas wale cluster centre se jodkar rows ko K groups mein baant-ta hai (jaise shoppers ko 'discount dhoondhne wale', 'weekend families' aur 'thok kharidne wale' mein baantna). Principal Component Analysis (PCA) darjanon milte-julte columns ko 2 ya 3 main directions mein compress karta hai taaki aap plot kar sako ya model tez chala sako. Anomaly detection (jaise Isolation Forest) credit-card fraud ya server spike jaise ajeeb events pakadta hai.

🪜 Step by step

  1. Numeric columns ko StandardScaler se saaf aur standardise karo taaki har feature ka mean 0 aur standard deviation 1 ho.
  2. Clustering ke liye K ki alag values (2 se 8) pe KMeans chalao aur elbow curve, silhouette score aur sabse zaroori: kya groups ka business matlab banta hai, yeh dekho.
  3. Har cluster ke average features dekhkar use insaani naam do ('baar-baar chhota saamaan kharidne wale').
  4. Bahut columns wali tables mein 2D plot banane ke liye PCA(n_components=2) lagao, ya 95% variance bachaane jitne components rakho.
  5. Bina labels ke anomalies pakadne ke liye IsolationForest chalao aur top 1% sabse ajeeb rows ko domain experts ke saath check karo.

🔑 Zaroori shabd

K-means clustering
Cluster centres (centroids) ko unke points ke average pe le jaakar data ko K groups mein baant-ta hai.
PCA (Principal Component Analysis)
Bahut saare correlated features ko kuch uncorrelated components mein compress karta hai jo zyaadatar variance bacha kar rakhte hain.
Anomaly detection
Aisi rare rows dhoondhta hai jo normal patterns se bilkul alag dikhti hain.

👀 Example dekho

python
from sklearn.preprocessing import StandardScaler
from sklearn.cluster import KMeans

X_scaled = StandardScaler().fit_transform(customers[["orders_per_month", "avg_bill"]])
kmeans = KMeans(n_clusters=3, random_state=42)
customers["segment"] = kmeans.fit_predict(X_scaled)

K-means ya PCA se pehle features hamesha scale karo taaki badi unit (rupaye) chhoti unit (order count) ko daba na de.

⚠️ Aam galtiyaan jinse bachna hai

  • Bina scale kiye features ya IDs pe k-means chalana, jisse bekaar clusters bante hain.
  • Supervised pipeline mein train/test split se pehle poore data pe StandardScaler ya PCA fit karna (data leakage).

✅ Jaldi se check karo

K-means clustering chalane se pehle features ko standardise (jaise StandardScaler) kyun karna chahiye?

  1. K-means distance naapta hai: bina scaling ke hazaaron wala column (salary) chhote number wale column (tenure) pe bhaari pad jaata hai
  2. Scaling missing rows apne aap mita deta hai
  3. K-means sirf text columns leta hai
Jawaab dekho

A. K-means distance naapta hai: bina scaling ke hazaaron wala column (salary) chhote number wale column (tenure) pe bhaari pad jaata hai: Jab tak saare features ek jaise scale pe na laaye jaayein, Euclidean distance pe sabse bade numbers wale feature ka hi kabza rehta hai.

🙋 Seekhne wale yeh poochhte hain

K-means kab fail hota hai?

Jab clusters gol na hon, size mein bahut alag hon, ya bahut outliers hon. DBSCAN ya HDBSCAN jaise density-based methods ajeeb shapes aur noise ko behtar sambhalte hain.

Kya unsupervised learning supervised models ki madad kar sakti hai?

Haan! Cluster IDs ya centroid se doori XGBoost ke liye acche features bante hain, aur anomaly scores batate hain ki insaanon ko pehle kaunsi rows label karni chahiye.

🎯 Is topic pe interviews mein poochhe jaane wale sawaal

Pehle khud bolkar jawaab dene ki koshish karo, phir model answer kholo.

K-means clustering, PCA aur anomaly detection kaise kaam karte hain, aur pehle features scale karna kyun zaroori hai?

💬

K-means bina label wali rows ko K clusters mein baantta hai: baar-baar har point ko sabse kareebi cluster centre deta hai aur phir har centre ko uske points ke average pe le jaata hai. PCA sabse zyaada variance wali dishaayein dhoondhta hai aur high-dimensional features ko kuch orthogonal components pe project karta hai. Isolation Forest features ko randomly kaat ke anomalies pakadta hai—outliers akele hote hain aur bahut kam splits mein alag ho jaate hain. Kyunki k-means aur PCA Euclidean distance aur variance pe chalte hain, bina scale kiya feature jaise rupayon mein salary (0 se 2,000,000) age (18 se 70) ko poori tarah daba dega, isliye main pehle features ko zero mean aur unit variance pe standardise karta hoon.

✅

  • K-means: kareebi centroid do, centroids update karo; K elbow/silhouette + domain samajh se chuno
  • PCA: correlated columns ko max variance ki dishaon mein compress karo
  • Isolation Forest: anomalies kam random splits mein alag ho jaati hain
  • Pehle features standardise karo taaki bade unit wale columns distances pe haavi na hon

: Dekhta hai ki aap fit() call karne se aage distance-based unsupervised learning samajhte ho ya nahi.

📌 Yaad rakho

Labels nahi hain? Milte-julte items cluster karo (k-means), columns compress karo (PCA), ya outliers pakdo — aur pehle scale zaroor karo.
