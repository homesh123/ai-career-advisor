🫧 Unsupervised learning: clustering, PCA and anomaly detection

EnglishHinglish

🏠 Real-life example

Imagine dumping a jar of mixed coins on a table without labels. Even if nobody tells you their names, you naturally sort them into piles by size, weight and colour — and if one plastic button is hiding inside, it stands out immediately. Unsupervised learning does the same: it groups similar rows (clustering), summarises many columns (PCA), and spots weird outliers (anomaly detection) without needing labels.

💡 In simple words

Most company data has no labels. Unsupervised learning finds structure in unlabelled data. K-means clustering groups rows into K clusters by putting each point with its nearest cluster centre (for example, grouping shoppers into 'bargain hunters', 'weekend families' and 'bulk buyers'). Principal Component Analysis (PCA) compresses dozens of correlated columns into 2 or 3 main directions so you can plot or speed up models. Anomaly detection (like Isolation Forest) flags unusual events such as rare credit-card fraud or server spikes.

🪜 Step by step

  1. Clean and standardise numeric columns with StandardScaler so every feature has mean 0 and standard deviation 1.
  2. For clustering, run KMeans for several values of K (say 2 to 8) and check the elbow curve and silhouette score — plus whether the segments make business sense.
  3. Inspect each cluster's average features to give it a human name ('high-frequency small-basket shoppers').
  4. For high-dimensional tables, use PCA(n_components=2) to visualise clusters on a 2D scatter plot, or keep enough components to explain 95% of variance.
  5. For anomaly detection without labels, fit IsolationForest and review the top 1% most anomalous rows with domain experts.

🔑 Key terms

K-means clustering
Splits data into K groups by iteratively moving cluster centres (centroids) to the average of their points.
PCA (Principal Component Analysis)
Compresses many correlated features into a few uncorrelated components that keep most of the variance.
Anomaly detection
Finds rare rows that look very different from normal patterns.

👀 See it in action

python
from sklearn.preprocessing import StandardScaler
from sklearn.cluster import KMeans

X_scaled = StandardScaler().fit_transform(customers[["orders_per_month", "avg_bill"]])
kmeans = KMeans(n_clusters=3, random_state=42)
customers["segment"] = kmeans.fit_predict(X_scaled)

Always scale features before k-means or PCA so big units (rupees) don't drown out small units (order count).

⚠️ Common mistakes to avoid

  • Running k-means on unscaled features or one-hot encoded IDs, producing meaningless clusters.
  • Fitting StandardScaler or PCA on the entire dataset before train/test split when using them inside a supervised pipeline (data leakage).

✅ Quick check

Why must you standardise features (e.g. StandardScaler) before running k-means clustering?

  1. K-means uses distance: without scaling, a column in thousands (salary) dominates a column in single digits (tenure)
  2. Scaling deletes missing rows automatically
  3. K-means only accepts text columns
Show answer

A. K-means uses distance: without scaling, a column in thousands (salary) dominates a column in single digits (tenure): Euclidean distance is dominated by whichever feature has the largest numerical scale unless all features are put on a similar scale first.

🙋 Questions learners ask

When does k-means fail?

When clusters have non-spherical shapes, very different sizes, or lots of outliers. Density-based methods like DBSCAN or HDBSCAN handle irregular shapes and noise better.

Can unsupervised learning help supervised models?

Yes! Cluster IDs or distance-to-centroid can be great features for XGBoost, and anomaly scores help prioritise which unlabelled rows humans should label first.

🎯 Asked in interviews on this topic

Try answering out loud first, then open the model answer.

How do k-means clustering, PCA and anomaly detection work, and why must you scale features first?

💬

K-means groups unlabelled rows into K clusters by repeatedly assigning each point to the nearest cluster centre and then moving each centre to the average of its assigned points. PCA finds the directions of maximum variance and projects high dimensional features onto a few orthogonal components. Isolation Forest spots anomalies by randomly splitting features—outliers sit alone and get isolated in very few splits. Because k-means and PCA rely on Euclidean distance and variance, an unscaled feature like salary in rupees (0 to 2,000,000) will completely dominate age (18 to 70), so I always standardise features to zero mean and unit variance first.

✅

  • K-means: assign to nearest centroid, update centroids; pick K via elbow/silhouette + domain sense
  • PCA: compress correlated columns along directions of max variance
  • Isolation Forest: anomalies are isolated in fewer random splits
  • Standardise features first so large-unit columns don't dominate distances

: Tests whether you understand distance-based unsupervised learning beyond calling fit().

📌 Remember

No labels? Cluster similar items (k-means), compress columns (PCA), or flag outliers — and always scale first.
