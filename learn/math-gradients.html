⛰️ Gradients and gradient descent: how models improve

EnglishHinglish

🏠 Real-life example

Imagine you're on a foggy hill at night and need to reach the bottom. You can't see far, so you feel the slope under your feet and take a small step downhill. Then you repeat. The slope is the gradient, each step is an update, and the step size is the learning rate. That's exactly how neural networks learn.

💡 In simple words

A model's 'loss' is a number measuring how wrong its predictions are. The gradient tells you which direction each parameter should move to reduce the loss, and how strongly. Gradient descent repeatedly nudges all parameters a little in that downhill direction. If the learning rate is too big you overshoot and bounce around; too small and training takes forever. Backpropagation is the efficient method, using the chain rule from calculus, that computes gradients for millions of parameters at once. Optimisers like Adam are smarter versions of gradient descent.

🎬 See how it works

Training is a ball rolling down the loss curve: each step goes downhill, and the learning rate sets the step size. It stops at the lowest loss.

🪜 Step by step

  1. Start with random weights; the model's predictions are bad.
  2. Measure how bad with a loss function (for example, average squared error).
  3. Compute the gradient: for each weight, which direction makes the loss go up, and how steeply.
  4. Update each weight a small step in the opposite direction: weight = weight − learning_rate × gradient.
  5. Repeat over many mini batches until the loss stops improving on validation data.

🔑 Key terms

Loss
A number measuring how wrong the model is. Lower is better.
Learning rate
How big a step to take on each update.
Backpropagation
The method that computes gradients through all the layers of a network.

👀 See it in action

python
# Find w so that w * 3 ≈ 12 (answer: 4)
w, lr = 0.0, 0.05
for step in range(20):
    pred = w * 3
    loss = (pred - 12) ** 2
    grad = 2 * (pred - 12) * 3     # slope of the loss
    w -= lr * grad                 # step downhill
print(round(w, 3))   # → 4.0

The whole idea of training in 7 lines: predict, measure the error, step downhill, repeat.

⚠️ Common mistakes to avoid

  • Learning rate too high: loss jumps around or explodes. Too low: training crawls. Try a few values.
  • Not plotting the loss curve. It's the quickest way to see if training is working.

✅ Quick check

Training loss jumps up and down wildly and never settles. A likely fix is…

  1. Increase the learning rate
  2. Delete the test set
  3. Decrease the learning rate
Show answer

C. Decrease the learning rate: Steps that are too big overshoot the bottom. Smaller steps settle down.

🙋 Questions learners ask

Do I need to calculate gradients by hand?

No. Frameworks like PyTorch compute them automatically (autograd). Understanding the idea is what matters.

What is Adam?

An optimiser that adapts the step size for each weight using recent gradients. It's a strong default for neural networks.

🎯 Asked in interviews on this topic

Try answering out loud first, then open the model answer.

What is regularisation? What's the difference between L1 and L2?

💬

Regularisation adds a penalty for large weights to the loss, which keeps the model simpler and reduces overfitting. L2, also called ridge, penalises the square of weights, so it shrinks all weights smoothly towards zero but rarely to exactly zero. L1, also called lasso, penalises the absolute value, which pushes some weights to exactly zero, so it also does feature selection. In neural networks we also use dropout and weight decay, which is L2 in practice.

✅

  • Penalty on weight size added to the loss
  • L2 shrinks smoothly; L1 makes some weights exactly zero
  • Strength is a hyperparameter tuned on validation data

: Standard ML theory; they may follow up with why L1 creates zeros.

Explain gradient descent in simple words. What does the learning rate do?

💬

Imagine you're on a hill in fog and want to reach the bottom. You feel which way the ground slopes and take a step downhill, again and again. Gradient descent does the same with the model's error: the gradient tells us which direction increases the error, so we move the weights a small step in the opposite direction. The learning rate is the step size. Too big and you overshoot and bounce around; too small and training is very slow. In practice we use mini batches and optimisers like Adam.

✅

  • Loss = how wrong the model is; gradient = direction of steepest increase
  • Update weights opposite to the gradient
  • Learning rate = step size, with the risk of too big or too small
  • Mention mini batch SGD or Adam

How would you implement logistic regression from scratch?

💬

I'd explain the steps, then code them in NumPy. One, initialise weights and bias to zeros. Two, compute z = X·w + b and the prediction p = sigmoid(z). Three, the loss is binary cross entropy. Four, the gradient is simple: dw = Xᵀ(p − y) / n and db = mean(p − y). Five, update w and b by subtracting learning rate times the gradient, and loop for some epochs. I'd add a check that the loss goes down, clip probabilities to avoid log of zero, and test on a tiny dataset where I know the answer.

✅

  • Sigmoid of a linear combination
  • Binary cross entropy loss
  • Gradient = Xᵀ(p − y)/n
  • Update loop; sanity checks for numerical stability

: ML coding rounds in 2026 often ask for algorithms from scratch, not just library calls.

What's the gradient of softmax combined with cross entropy loss?

💬

If p is the softmax output and y is the one hot true label, the gradient of the cross entropy loss with respect to the logits is simply p − y. Intuitively, for the correct class the gradient is p − 1, which is negative, so training pushes that logit up; for wrong classes it's p, pushing those logits down in proportion to how confident the model wrongly was. This clean result is why softmax and cross entropy are combined in one function in frameworks, which is also more numerically stable using the log sum exp trick.

✅

  • Gradient w.r.t. logits = p − y
  • Intuition for correct vs wrong classes
  • Implemented together for numerical stability (log sum exp)

: Labs report this as a quick filter: can you derive basics cleanly?

What are vanishing gradients, and what fixed them in modern networks?

💬

In deep networks, gradients are multiplied through many layers during backpropagation. If those factors are below one, the gradient shrinks to nearly zero by the time it reaches early layers, so they stop learning. Fixes that made deep networks work: activations like ReLU instead of sigmoid; residual or skip connections, which give gradients a direct path back; normalisation layers like LayerNorm; careful weight initialisation; and optimisers like Adam. Transformers rely heavily on residual connections and LayerNorm.

✅

  • Gradients shrink through many layers
  • ReLU, residual connections, normalisation, good initialisation
  • Link to transformers' design

📌 Remember

Gradient = which way is downhill. Learning = many small steps down the loss hill.
